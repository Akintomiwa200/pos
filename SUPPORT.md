# Support

## Questions and bugs

- **Bugs:** open a GitHub issue with the Bug report template.
- **Features:** use the Feature request template.
- **Security:** do not use issues. Follow [SECURITY.md](SECURITY.md).

Please search existing issues before opening a new one.

## What to include

For till or HQ problems, say which app you were in, the browser or OS, and the
steps that led to the failure. Do not paste production till codes, staff
passwords, or customer data.

## Community

This project is maintained in this repository. There is no separate support
forum yet. Pull requests that improve docs are welcome; see
[CONTRIBUTING.md](CONTRIBUTING.md).
