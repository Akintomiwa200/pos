# Price Check

Handheld price lookup (Vite + React). Native Windows EXE and Android APK: Tauri 2 in `src-tauri/`.

```bash
pnpm install
pnpm dev
```

http://localhost:1430 — enter the API origin in the app (or set `VITE_API_URL`).

Windows installer and Android APK: see **[docs/build](../docs/build/README.md)**.

```bash
pnpm tauri:build
pnpm tauri:apk
```
